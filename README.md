# KB16 Codex Desktop Macropad

An unofficial VIA layout for the KeebMonkey Megalodon KB16-01, designed for the Codex desktop app on macOS. It provides task navigation, dictation and voice controls, workflow-prompt macros, agent/review layers, and encoder mappings inspired by the Codex Micro.

## Files

- [`outputs/KB16-01_Codex_Desktop_v1.layout.json`](outputs/KB16-01_Codex_Desktop_v1.layout.json) — layout to import into VIA
- [`outputs/KB16_Codex_Desktop_Setup.md`](outputs/KB16_Codex_Desktop_Setup.md) — setup instructions and complete physical map
- [`outputs/KB16_Codex_Shortcut_Manifest.json`](outputs/KB16_Codex_Shortcut_Manifest.json) — machine-readable shortcut reference

## Quick start

1. Connect the KB16-01 by USB and open [VIA](https://usevia.app/).
2. Import the saved layout JSON.
3. Follow the setup guide to assign the Live Voice hotkey and any optional Codex commands exposed by your installed app.

This targets USB ID `0xD010:0x1601`. Effort and extended review controls require corresponding commands to appear in Codex under **Settings → Keyboard Shortcuts**.
